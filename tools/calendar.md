# Google Calendar Integration

MCP namespace: `mcp__Google_Calendar__*`. Primary calendar: `davidonewaycapital@gmail.com` (also has a read-only US holidays calendar).

## Available operations

| Tool | Use |
|------|-----|
| `list_calendars` | List calendars the account can access |
| `list_events` | List events on a calendar in a time range |
| `get_event` | Read a specific event's details |
| `suggest_time` | Find open slots for a proposed duration/window |
| `create_event` | Create a new event |
| `update_event` | Modify an existing event |
| `delete_event` | Remove an event |
| `respond_to_event` | Accept/decline/tentatively respond to an invite |

## Conventions

- **Internal holds (no external attendees)**: create directly with `create_event`. Safe to do without asking — nothing is sent to anyone outside this account.
- **Anything with an external attendee** (a prospect, a client, a partner): always run `suggest_time` first to find a real open slot, then confirm the specific time and attendee list with the user before calling `create_event`. Adding an external attendee sends them a real calendar invite — that's a visible, hard-to-undo action and needs a human okay first.
- Use for booking discovery calls, demo slots, and client check-ins generated by sales/PM agents — don't build a separate scheduling mechanism.

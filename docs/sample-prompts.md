# Sample prompts — from Joey's OUR TURN pipeline (2.0 skills)

Hero prompts pulled straight from Joey's OUR TURN production, written by the updated 2.0 skills and used in the actual video. Source: his [upgrade video](https://youtu.be/4TXaAnittHs) and [Notion write-up](https://pyrite-mallow-3b0.notion.site/The-Claude-skills-that-run-my-AI-Cinema-workflow-got-an-UPGRADE-Here-s-Why-36d49da027d780ff928ef70a16148369). Paste them into Higgsfield, swap your references in, see how the structure works.

In Joey's words: read them once. Then read them again paying attention to what's **not** there.

No brand names — no Alexa, no Panavision, no Kodak. No fixture names. No character names. No song or lyric references. No real-world product labels. The model doesn't render those — it renders the behavior behind them, so the skill writes the behavior directly.

## What you'll see instead

- **Frame Map first, identity second.** Every prompt opens by anchoring subjects to screen positions, depth layers, contact points, and gaze. The model can't drift a character to the wrong side of the frame if the frame is locked before identity even shows up. This is the structural change that did more for multi-character consistency than anything else.
- **Subject Locks per character.** Each named subject gets a dedicated reference image slot and a Subject Lock block that pins pose, gaze, contact points, and state — without re-describing what the reference sheet already carries. Identity is anchored to the reference. The prompt only describes what changes shot to shot.
- **Lighting as physics.** Direction, quality, temperature, motivation. "Warm hard rim from camera-right above, cool ambient fill from behind, faint uplight catching the underside of the jaw." The model knows exactly what to render because it's described in terms the model actually understands.
- **Camera Capture as one closing line.** Body, lens, filter, movement, stock, grade, frame rate, runtime — all in a single trimmed paragraph at the end. Same look the brand-name stack used to chase, none of the jargon.
- **Diegetic audio only.** Footsteps, fabric, breath, room tone. No music, no lyrics, no dialogue cues tied to a song. Music lives in the Higgsfield UI, not the prompt.
- **Anti-plastic skin language.** Per-zone specular kill — zero shine on forehead, nose bridge, cheekbones, temples, chin. Real peach fuzz at the jaw and hairline. Subsurface scattering. Skin reads matte without going harsh.

## Real expectations (Joey's honesty section)

- **You will still regenerate.** Just less. On Hunters he was burning 8–10 takes per shot fighting the prompt. With the skills doing the prompt engineering it's more like 2–3 takes to pick from. Different problem. Cheaper problem. But not zero.
- **The skills don't write themselves.** Joey built these encoding his taste, his rules, his mistakes. If your taste is different, fork them and make them yours. Don't treat them as final.
- **Consistency across shots is still the hardest problem.** Locked character reference sheets help. Separating identity from styling helps. The skills enforce both. But you'll still get drift on long sequences. The fix is more reference passes and tighter wardrobe locks — there's no prompt that solves it for you.
- **Hit rate scales with prep.** The shots that worked first try in OUR TURN all had locked references, locked wardrobe, locked environment plates before the video prompt ever ran. The shots that took 6 tries were the ones where a step got skipped. Every time. The pipeline is what makes the prompt cheap.
